Found that some questions don't have correct options. Even though the question is solvable, since we are generating both the question and the answer in the same request, the LLM is pretty sure that it's "incorrect" answer is the correct one. I proposed a challenge agent that, when a challenge is invoked, will challenge the incorrect question. AI suggested a Validation agent that validates all questions once they are generated. But that is unnecessary since majority questions already have correct answers. So I challenged the AI's suggested architecture because it's better to make 2 LLM calls for one challenge (one to solve the question and one to check if the answer is in the options) instead of making 10 LLM calls for each generated test.
